# Titan Pickaxe — Minecraft 1.20.1 Forge 47.4.20

Complete Forge project for Minecraft 1.20.1.

## Features
- Titan Pickaxe
- 10x10 horizontal mining square
- Diamond-tier base tool
- Gradle wrapper
- GitHub Actions build workflow
- Item texture and model
- Creative tab registration

## Versions
- Minecraft 1.20.1
- Forge 47.4.20
- Java 17

## Give command
/give @p titanpickaxe:titan_pickaxe

## GitHub Actions
Push the project to GitHub. The workflow in `.github/workflows/build.yml`
will build the mod automatically. After it finishes, open the workflow run
and download the `TitanPickaxe-1.20.1-Forge-47.4.20` artifact.
